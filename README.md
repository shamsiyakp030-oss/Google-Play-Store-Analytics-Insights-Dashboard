# 📌 Project Overview

The **Google Play Store Analytics Insights Dashboard** is an end-to-end **Data Analytics and Business Intelligence project** developed as part of an **AI & Data Science Internship**.

The project focuses on transforming raw Google Play Store application data into meaningful business insights using:

- Python Data Analytics
- Exploratory Data Analysis
- Interactive Visualization
- Machine Learning
- Power BI Reporting
- Streamlit Dashboard Development


The dashboard provides insights into:

- Application performance
- User engagement
- Category trends
- Ratings and reviews
- Install patterns
- Pricing models
- Market segmentation


The objective is to demonstrate how data-driven approaches can help businesses understand application success factors and improve decision-making.

# 📝 Executive Summary

The Google Play Store contains millions of applications across multiple categories with different ratings, reviews, install counts, sizes, and pricing strategies.

Analyzing this large volume of application data manually is difficult.

This project builds an interactive analytics platform that helps users explore application performance through:

- Data preprocessing
- Statistical analysis
- Interactive dashboards
- Machine learning segmentation
- Business intelligence reporting


The final solution enables users to identify:

- High-performing application categories
- User preference patterns
- Market opportunities
- Application success indicators


---

# 🎯 Business Problem Statement

Mobile application markets are highly competitive. Developers and businesses need data-driven insights to understand:

- Which categories attract more users?
- What factors influence application ratings?
- How does application size affect performance?
- Which pricing strategy performs better?
- What characteristics define successful applications?


This project addresses these challenges by developing a complete analytics dashboard using real-world application data.

# ⚙️ Installation & Setup


## Step 1: Clone Repository


```bash
git clone https://github.com/shamsiyakp030-oss/google-play-store-analytics-insights-dashboard.git
```


## Step 2: Navigate Project Folder


```bash
cd google-play-store-analytics-insights-dashboard
```


## Step 3: Install Dependencies


```bash
pip install -r requirements.txt
```


## Step 4: Run Application


```bash
streamlit run app.py
```
